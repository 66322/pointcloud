# 开题后的新增实验规划

2026-11-26。依据为 11 月 24 日保存的《融合视觉与激光点云信息的协同语义分割方法研究》开题 PPT（文件名含 20261123，共 26 页）。第 12–19 页给出拟解决的问题和网络示意，第 21–23 页说明数据与前期工作。以下模型、处理强度、对照、种子和比较规则均为本次新增设计。先登记方案，再提交代码。服务器成绩按实际回执追加。

## 研究问题、对照和判据

| 问题 | 只改变的机制和直接对照 | 主判据 | 需要一起解释的结果 |
|---|---|---|---|
| 一　在外参偏差下，模型能否放弃错误的图像证据？ | 固定中心 → 可学习局部偏移与语义打分 → 加深度一致性 → 加拒配。每一步与前一步同条件配对 | 预先指定 ±3° 两个方向平均的 mIoU 差，重点比较有无拒配 | 正常输入、±1° 和 0.2 m 平移；报告逐类 IoU、有效视觉质量分配。仅局部候选获益时，不能把收益归给拒配 |
| 二　点云帮助图像与图像帮助点云，是否需要独立权重？ | 在同一对应模块上比较单向、双向共享权重、双向独立权重；移除质量线索时保留权重网络尺寸 | 对局部暗化与点云稀疏两项的配对差取等权平均，重点比较独立与共享；分别列出两项 | 加入模糊、联合退化及正常输入，记录两个方向的权重。稀疏实验另报保留点数。质量盲对照区分质量统计与新增容量 |
| 三　相机缺失时哪些点受益于补偿？ | 主视角 → 加相邻视角 → 加局部点云后备 → 加同帧全视角自蒸馏；所有方法相同机会见到训练缺失 | 两个互补三相机子集上，邻视角模型相对主视角的等权配对差；零相机上，有无蒸馏的配对差 | 逐一保留六台相机中的一台。按主视角有效、仅邻视角有效、无有效视角分别报告点数及 IoU。若只有总体变化，须保留分组解释的不确定性 |

以 nuScenes-lidarseg 的原训练集优化，6,019 帧完整验证集固定为同一顺序。点云始终存在。原 DITR 完整验证 82.48% 与原权重多视图均值 82.64% 作历史参照。在单种子、固定三路下，既有 camera dropout 为 73.13%，同条件 control 为 60.79%。这些数值来自既有实验，只作选题依据。[既有结果和来源](../EXPERIMENT_MASTER.md)

## 训练模型

| 配置名 | 实验处理 |
|---|---|
| control | 原 DITR 融合结构，接受与本批其余模型相同的数据处理及训练预算 |
| p_lidar | 共用 PTv3 点云编码和解码，仅以点特征预测，给出全图像缺失的参照 |
| p_center | 在相同点云骨干后，只取主相机中心投影的视觉特征。作为新融合位置的结构对照 |
| p_offset | 用已编码的点特征预测多尺度候选位移，用语义相似度加权视觉特征 |
| p_geom | 在候选评分中加入相机坐标深度与投影稀疏深度缓冲的一致性。无深度支持单独编码 |
| p_imgdepth | 在 p_geom 上增加单目图像深度头。用训练帧中标定未受扰动的可用相机投影深度监督图像 token，推理时用图像独立预测的深度核对候选 |
| p_reject | 候选与一个空匹配项竞争；空项质量高时衰减图像残差。零观测直接回点云 |
| p_oneway | 在 p_reject 上加入局部质量和图像到点云的动态权重，仅运行图像到点云方向。与 p_asym 配对以检验写回图像网格的增量 |
| p_shared | 先将点特征按投影写回视觉 token，再从更新后的图像采样。两个方向共用系数 |
| p_asym | 对同样两个方向使用独立系数。权重利用局部亮度、对比度、梯度、点密度/局部结构、特征内容和对应可信度 |
| p_blind | 与 p_asym 配对，将局部质量统计置零；网络宽度、双向计算与可信度输入相同 |
| p_neighbor | 在 p_asym 上增加逐点邻视角补偿，仅使用物理相邻且实际可见的相机；引入相对朝向、基线长度 |
| p_prior | 在无观测路径加入局部点特征的均值、最大值和点自身特征构成的后备残差 |
| p_distill | 在 p_prior 上加入同帧全视角、停止梯度的在线教师，对原可观测而当前走后备的点施加 KL；推理仅保留学生 |

新结构在 PTv3 解码后注入，先取得独立点特征，避免后备分支读到上游多级视觉残差。图像采用冻结 DINO 高层特征和 RGB 局部细节。深度缓冲由点云投影生成，是遮挡代理，缺少独立稠密深度真值。双向实验的图像分支更新真实图像网格；评价目标始终是三维点标签。当前实现检验单帧空间对应，时间不同步需另设有时间戳和运动补偿的协议。

实现前细化了两个对照。全体点随错误外参一起移动时，投影深度缓冲也会移动，因此拒配的直接对照固定为同时具有深度缓冲与单目预测的 p_imgdepth。单目预测只使用图像作为输入，深度监督来自训练集。双向写回的直接对照固定为 p_oneway，两个方向是否需要独立权重仍比较 p_asym 与 p_shared。

## 数据处理与评测矩阵

- **外参组**在相机坐标系内对点到相机变换追加绕竖直轴的 ±1°、±3° 旋转，或沿相机 x 轴平移 +0.20 m，重新计算投影、深度和视场。真实图像、标签与点坐标保持对应。旧 4px 结果单独列示。
- **质量组**对图像中央区域暗化或模糊，对 20 m 外方位扇区内的点固定随机保留 25%，另设暗化与稀疏共同发生。所有模型共享逐帧扰动。稀疏条件在完全相同的保留点上评价。与干净条件比较稀疏损失时，先把干净预测限制到相同点集。
- **缺失组**按相机名称固定子集。两个三路组交替覆盖环视六个方向；六个单路组和零路单列。主视角由原本有投影的相机按归一化中心距离确定，之后再施加可用性掩码。邻接关系按物理环序定义，独立于字典下标。
- **真实天气**将事先固定的 nuScenes 权重直接用于 SemanticSTF 官方 val 250 帧，分别汇总雪、雨、轻雾、浓雾和全部帧。本地分发版提供单前视 RGB、五列点文件、逐点标签、标定及天气清单。评估 car、bicycle、motorcycle、truck、person、road、sidewalk、terrain、vegetation 九个预先对应的类别，忽略其余 GT，对已入选 GT 的范围外预测计错。报告共同类别数、有效点数及各天气样本量；单前视数据用于质量泛化，多相机补偿只在 nuScenes 检验。[SemanticSTF 数据与原论文](https://github.com/xiaoaoran/SemanticSTF) · [原采集平台与标定](https://github.com/princeton-computational-imaging/SeeingThroughFog)

三组扰动分别报告；另用完整模型覆盖每一组。所有拟报告的模型先登记，包含表现持平、下降、执行失败和缺测。完整矩阵由配置展开，按条件共享同一训练产物。需要验证更多缺失图样时，可另开批次扩展至六台相机的 64 个子集。

## 配对、预算和统计

- 三个独立训练种子为 20261101、20261117、20261126。每个种子内固定样本顺序、原增强、补充退化与缺失分布；不相互继承微调权重。每配置 30 轮、每卡 batch 6，原学习率组和最后一轮权重；不设运行时限。时间较长时可分种子续排。
- 同一初始化与预算下对比。独立/共享门使用同尺寸双输出层；共享时将两项取均值。记录可训练参数、成功更新/AMP 跳步、端到端耗时和峰值显存。对计算额外增加的蒸馏单列训练成本。
- 对每个主比较先在同种子、同验证条件内计算实验组减直接对照的百分点差，再按上表等权汇总条件，最后报告三个种子的差值、均值与样本标准差。少于三个完整配对时标明进度，保留缺测；点、碎片或相邻帧不充作训练重复。次要分析报告固定处理下的逐类和距离/路由分层，有效类别并集与支持数随表提供。
- 结果解释同时查看干净输入及压力条件；若方向随种子或子集变化，则如实注明。工程故障在运行状态和日志中记录，不能填作 0 分。跨库九类分数与 nuScenes 16 类分开列。
- 两卡沿用每卡一个独立任务、空闲即接续的方式；训练完成后，同一权重派生多条件验证。重启保留原输出与提交号。每次运行记录执行提交、有效配置、种子、数据和划分、条件、状态、指标及回执来源。大权重和逐点结果留服务器，GitHub 同步代码、规划及轻量记录。
